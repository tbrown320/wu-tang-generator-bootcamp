# Project: Wu Tang Name Generator!

### Goal: Create a Wu-Tang Clan name generator. Present the user with 5 survey questions and based on those answers randomly generate their name. The name doesn't have to be exact names, but Wu-Tang sounding-ish names. Ex: Childish Gambino (who actually got his name from a Wu-Tang name generator).

### Features:

- Name generator based on personality questions
- You choose from 3 answers to 5 personality questions
- One all fields are chosen, click 'What's my name' for your Wu-Tang Clan name!

### Tech Used:

- HTML
- Javascript
- CSS

### Lessons Learned

- consistent parameter usage is essential
- usage of fieldsets to hold questions and answers
- executing functions on the server side and just returning a json can help organize information
